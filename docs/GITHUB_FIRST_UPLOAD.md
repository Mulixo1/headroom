# First GitHub upload (for maintainers)

If you already have `gh` authenticated:

```bash
cd headroom
gh repo create Mulixo1/headroom --public --source=. --remote=origin --push --description "Local macOS menubar + dashboard for GPT and Grok remaining usage"
```

If remote already exists:

```bash
git remote add origin https://github.com/Mulixo1/headroom.git
git push -u origin main
```

https://github.com/Mulixo1/headroom
